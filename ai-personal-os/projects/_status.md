# Project status — heartbeat

> A leading indicator of project health. The goal: catch stalls **weeks** before a goal goes red
> in `goals/yearly.md`, and stop projects from drifting in limbo. Updated in `/weekly-review`.

## Rules

- **Statuses:** `Active` — in focus, moving · `Parked` — deliberately paused, no guilt · `Dead` — closed (moved to `_archive/` with a note).
- **Stall signal:** an `Active` project with no progress for **2+ weeks** → 🚩 → fork: revive (one action + an external rail) / park / kill.
- **WIP limit: Active ≤ 5** (tune to your capacity). If Active > limit — don't start anything new until something moves to Parked/Dead.
- **"Last progress"** = a task from weekly.md, a commit, or a client conversation this week.
- **Entering Active:** a new project gets `Active` only after passing the alignment gate (`goals/idea-to-production.md` → "Gate 0").
