## Routing by topic

Came in with a topic → read only these files:

| Topic | Files |
|-------|-------|
| Anxiety / falling behind | `self/states.md` + `self/triggers.md` + relevant protocol |
| Doomscrolling / focus loss | the relevant protocol + `frameworks/act.md` |
| Patterns / who am I / traits | `self/traits.md` |
| A specific framework | `frameworks/<name>.md` |
| Deep reflection / a hard day | create/append `reflections/YYYY-MM-DD.md` |
| Interpreting a dream | use `/dream` → `dreams/patterns.md` for recurring themes |
| Unclear topic | read this INDEX → if still unclear, ask the user |

## Layers (the ladder rule)

- **L1 provisional** (dated observations: `traits.md` → "Observations", `states.md`, `triggers.md`) —
  written daily/weekly, append-only.
- **L0 identity** (prose sections of those files + `values.md`) — slow, changes only in `/monthly-review`.
- Promotion L1 → L0: survived ≥1 month + recurred + not contradicted. Never from a single day.
